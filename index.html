Demander la suppression de mon compte

Cette demande reste possible sans connexion et après avoir désinstallé l’application.

1. Envoyer votre demande

Écrivez à lohourignongael@gmail.com, de préférence depuis l’adresse de votre compte. Objet : Suppression de compte — Catéchèse adulte Casablanca.

Indiquez seulement l’adresse du compte concerné. N’envoyez jamais votre mot de passe, un code de connexion ou une pièce d’identité spontanément.

Ouvrir ma messagerieLe bouton prépare un message : vous devez l’envoyer vous-même. Si rien ne s’ouvre, utilisez Gmail ou votre messagerie habituelle et copiez l’adresse ci-dessus. Aucun formulaire n’est collecté par cette page.

2. Vérifier que le compte vous appartient

Le support peut répondre à l’adresse enregistrée pour vérifier votre demande. Si vous n’y avez plus accès, indiquez-le afin de convenir d’une vérification adaptée.

3. Supprimer le compte et les données associées

La demande porte sur votre compte de connexion, son profil (courriel, rôle, année) et les données personnelles associées. Les sessions doivent être révoquées.

Si vos informations figurent aussi dans un dossier de catéchumène ou une photo, signalez-le pour qu’elles soient également traitées. Supprimer le compte d’un accompagnateur n’efface pas automatiquement les dossiers des autres personnes : les informations permettant de l’identifier doivent être examinées séparément.

Le traitement est manuel, après vérification. Le support confirme sa réalisation et précise les éventuelles données conservées pour un motif justifié, leur durée et le traitement des sauvegardes. Une simple désactivation ou un archivage ne constitue pas une suppression.

Une autre question sur vos données ?

Pour l’accès ou la rectification de vos données, utilisez également lohourignongael@gmail.com.
